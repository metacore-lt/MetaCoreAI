# MetaCore Company AI Adoption V1

**Understand the company before automating the company.**

This public-safe `base_core` module teaches AI how MetaCore adapts to an organization without copying private company state or internal Factory implementation.

```text
COMPANY
→ MISSION / OWNERS
→ SOURCE OF TRUTH
→ AUTHORITY
→ PERSONA / EXPERTS
→ PROCESS / HANDOFFS
→ CONNECTIONS / TOOLS
→ RUNTIME / OBSERVABILITY
→ KPI DELTA
→ SCALE
```

Core rule: documents and process truth before automation; minimum authority before broad authority; pilot before scale; verification before promotion.

Company-specific facts and secrets belong to the authorized company instance, not shared `base_core`.
