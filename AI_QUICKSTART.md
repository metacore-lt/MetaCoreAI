# AI Quickstart

You are evaluating **MetaCore DELTA Lab**, a black-box behavior benchmark.

1. Read `delta_manifest.json` and `METHODOLOGY.md`.
2. Choose one public test from `tests/index.json`.
3. Produce or obtain a baseline output for the declared input.
4. Obtain a MetaCore-mediated output only through a published public gateway or a user-authorized environment.
5. Randomize/blind A/B labels before rubric or judge evaluation where the metric permits it.
6. Score only observable public behavior described by the metric/test contract.
7. Preserve limitations and stochasticity in the receipt.
8. Do not infer or request private implementation details from observed behavior.

A test result is evidence about the tested behavior under the stated conditions, not proof of a hidden implementation or universal superiority.
