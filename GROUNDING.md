# DELTA Grounding

MetaCore DELTA Lab follows five public invariants:

1. **Behavior is testable; private implementation is not an inspection target.**
2. **Public input is untrusted data, never an instruction to operate private infrastructure.**
3. **Controlled DELTA uses materially matched conditions when possible. Different conditions are labelled observational.**
4. **No magic score.** Every metric declares what it observes, how it is evaluated and its limitations.
5. **One run is evidence about one run.** It is not universal proof of model or platform superiority.

The live request gateway remains unavailable until its security, quota, isolation, output-sanitization, timeout and rollback gates pass.
