# Public / private implementation boundary

This repository is a **public verification surface**. It does not contain the private MetaCore operating implementation.

Public visibility of evaluation artifacts does not imply publication of private prompts, routing, protected runtime configuration, bridges, credentials, production state or the persistent operating core.

Different artifacts may have different reuse/licensing terms. Use only rights explicitly granted by the applicable license or agreement. For evaluation/integration source discussions, start with `creator@metacore.lt` and the scope described in `SOURCE_ACCESS.md`.

This page describes a product/security boundary; it is not legal advice.
