# Human & Team Signal Mode — public method

MetaCore DELTA Context Lab includes two browser-local signal maps adapted from public MetaCore interaction patterns used across relationship, team and leadership surfaces.

They are **context instruments**, not diagnostic tests.

## Human Loop Map

The public demo asks for five self-reported fields:

1. trigger — the concrete moment that starts the loop;
2. touched need — what the moment seems to touch for the user;
3. usual reaction — what the user tends to do next;
4. breaker — what has interrupted the loop before;
5. next step — one small action under the user's own control.

Output is a structural map:

```text
TRIGGER → TOUCHED NEED → REACTION → BREAKER → NEXT STEP
```

The tool does not infer personality, attachment style, pathology, partner intent or relationship prognosis. It preserves the data as **self-report** and generates a next reflection question.

If user text contains violence, threat, coercion, self-harm or immediate-safety language, the demo stops ordinary pattern analysis and returns a human-safety boundary instead.

## Team Friction Snapshot

The public demo scores four operational dimensions with intentionally coarse values `3 / 6 / 9`:

- decision clarity;
- ownership clarity;
- communication friction;
- work rhythm.

The total range is `12..36`. The highest dimension becomes the current bottleneck signal. The result includes an operator-oriented mechanism, one next question and one suggested operational action.

This is **not HR assessment and not employee profiling**. It describes a self-reported team mechanism, not an employee trait or performance rating.

Safety/harassment/threat language stops routine optimization and requires a responsible human path.

## Leadership connection

The existing DELTA `Authority Gate` covers the complementary leadership pattern:

```text
actor → authentication → delegated mandate → scope → impact → approval boundary
```

This keeps team/leadership logic focused on roles, decisions and accountable action rather than psychological labeling.

## Privacy / cost boundary

Both instruments execute only in the browser. They do not use cookies, local storage, B1, a database or network calls.
